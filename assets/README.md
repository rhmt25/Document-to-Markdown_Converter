# MarkDocx application icon

Place the app icon here as `markdocx.png` before building:

```text
assets/markdocx.png
```

Use a square PNG. A 512 × 512 pixel image with a transparent background is recommended. The Windows build embeds this image into `MarkDocx.exe`; PyInstaller converts it to the Windows icon format using Pillow. The PNG should have comfortable padding so the artwork remains clear at small icon sizes.
