# Document to Markdown Converter

Windows desktop application for converting documents into editable Markdown.

## Current status

The first-phase PySide6 workspace shell is in place. Folder selection, Markdown editing/preview, saving, and reopening saved Markdown files are wired up. Document scanning/conversion and batch actions are planned for later phases.

## Run from source

1. Install Python 3.11 or newer.
2. Install dependencies: `python -m pip install -r requirements.txt`.
3. Start the application: `python main.py`.
