# Contributing

Thanks for considering a contribution. Bug reports, documentation improvements, and focused pull requests are welcome.

## Before making a change

- Search existing issues to see whether the problem or proposal is already being discussed.
- For a larger behavior change, open an issue first so scope and expected output can be agreed.
- Keep converter behavior general-purpose. Do not add rules that depend on a particular filename, author, journal, or subject.
- Do not add private documents or conversion outputs. Prefer small synthetic DOCX fixtures generated by the test suite.

## Local setup

Use Windows with Python 3.11 or newer:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

For UI changes, also launch `main.py` and inspect the workflow at normal and compact window sizes. For converter changes, add or update a synthetic regression fixture that covers the changed DOCX structure.

## Pull requests

Please include:

- The user-visible problem and the behavior you changed.
- The checks you ran and their results.
- A screenshot for visible UI changes.
- Any new dependency and why the project needs it.

Keep pull requests focused and update the user guide or conversion support notes when behavior changes. Do not include generated `build/` or `dist/` output, virtual environments, logs, sample documents, or local conversion results.
